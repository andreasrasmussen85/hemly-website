<div class="content">

  <h2>1. Introduktion</h2>
  <p>Hos Hemly respekterer vi dit privatliv. Denne privatlivspolitik beskriver, hvilke oplysninger vi indsamler, hvordan vi bruger dem, og hvilke rettigheder du har i forbindelse med dine personoplysninger.</p>
  <p>Hemly er en dansk boligvurderingsapp, der giver brugere mulighed for at søge på adresser og få prisestimater baseret på offentlige ejendomsdata.</p>

  <hr class="divider">

  <h2>2. Dataansvarlig</h2>
  <p>Den dataansvarlige for behandling af dine personoplysninger er:</p>
  <ul>
    <li><strong>Virksomhed:</strong> Hemly</li>
    <li><strong>E-mail:</strong> <a href="mailto:hej@hemly.dk">hej@hemly.dk</a></li>
    <li><strong>Hjemmeside:</strong> <a href="https://hemly.dk">hemly.dk</a></li>
  </ul>

  <hr class="divider">

  <h2>3. Hvilke oplysninger indsamler vi?</h2>
  <p>Hemly indsamler et minimum af data for at levere vores tjeneste:</p>
  <ul>
    <li><strong>Søgehistorik:</strong> Adresser du har søgt på gemmes lokalt på din enhed (ikke på vores servere)</li>
    <li><strong>Watchlist-data:</strong> Boliger du gemmer til din watchlist gemmes lokalt på din enhed</li>
    <li><strong>Tekniske data:</strong> Vi kan modtage anonyme fejlrapporter og app-performance data via Expo/React Native</li>
  </ul>
  <p>Vi kræver <strong>ingen login eller registrering</strong> for at bruge appen. Vi indsamler ikke dit navn, e-mail eller andre personoplysninger medmindre du kontakter os direkte.</p>

  <hr class="divider">

  <h2>4. Hvordan bruger vi dine oplysninger?</h2>
  <p>De begrænsede data vi behandler bruges udelukkende til:</p>
  <ul>
    <li>At levere og forbedre app-funktionaliteten</li>
    <li>At fejlsøge tekniske problemer</li>
    <li>At besvare henvendelser du sender os</li>
  </ul>
  <p>Vi sælger aldrig dine data til tredjeparter og bruger dem ikke til markedsføring.</p>

  <hr class="divider">

  <h2>5. Tredjeparts datatjenester</h2>
  <p>Hemly benytter følgende eksterne tjenester som kan behandle data:</p>
  <ul>
    <li><strong>DAWA (Danmarks Adressers Web API):</strong> Bruges til adresseopslag. Data behandles af Styrelsen for Dataforsyning og Infrastruktur.</li>
    <li><strong>Expo (React Native):</strong> Bruges til app-distribution og kan indsamle anonyme crash-rapporter.</li>
    <li><strong>Apple App Store:</strong> Behandler data i forbindelse med download af appen.</li>
  </ul>

  <hr class="divider">

  <h2>6. Dine rettigheder</h2>
  <p>Ifølge GDPR har du følgende rettigheder:</p>
  <ul>
    <li>Ret til indsigt i dine personoplysninger</li>
    <li>Ret til berigtigelse af forkerte oplysninger</li>
    <li>Ret til sletning ("retten til at blive glemt")</li>
    <li>Ret til begrænsning af behandling</li>
    <li>Ret til dataportabilitet</li>
    <li>Ret til at gøre indsigelse mod behandling</li>
  </ul>
  <p>Da Hemly ikke kræver login og gemmer data lokalt på din enhed, kan du til enhver tid slette alle data ved at afinstallere appen.</p>

  <hr class="divider">

  <h2>7. Cookies og tracking</h2>
  <p>Hemly-appen bruger ikke cookies. Vores hjemmeside (hemly.dk) bruger udelukkende teknisk nødvendige ressourcer (Google Fonts) og foretager ingen brugertracking.</p>

  <hr class="divider">

  <h2>8. Ændringer til denne politik</h2>
  <p>Vi kan opdatere denne privatlivspolitik fra tid til anden. Væsentlige ændringer vil blive kommunikeret via appen. Den seneste version er altid tilgængelig på hemly.dk/privatlivspolitik.</p>
